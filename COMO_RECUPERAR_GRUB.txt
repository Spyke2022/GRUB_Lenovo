==============================================================
  COMO RECUPERAR O GRUB - Lenovo Yoga Slim 7 14IMH9
  Multi-boot: Garuda Mokka/Sway, Windows 11, Arch ML4W, CachyOS, NixOS
==============================================================

Voce tem o script de recuperacao em dois lugares:

  1. No pendrive Ventoy, na pasta /Scripts/
  2. No GitHub: https://github.com/Spyke2022/GRUB_Lenovo

--------------------------------------------------------------
QUANDO USAR
--------------------------------------------------------------

Se o Windows ou uma atualizacao quebrar o boot novamente
(tela preta, GRUB sumiu, ou alguma distro parou de aparecer),
basta bootar no Garuda Mokka e rodar o script.

--------------------------------------------------------------
COMO RODAR
--------------------------------------------------------------

    sudo bash /caminho/restaurar-grub.sh

Exemplos de caminho:
  - Do pendrive:  sudo bash /mnt/ventoy/Scripts/restaurar-grub.sh
  - Do GitHub:    sudo bash ~/GRUB_Lenovo/restaurar-grub.sh

--------------------------------------------------------------
O QUE O SCRIPT FAZ
--------------------------------------------------------------

  - Reinstala o GRUB na EFI
  - Detecta automaticamente o hash atual do NixOS
    (que muda a cada nixos-rebuild)
  - Recria as 6 entradas na ordem certa
  - Regenera o grub.cfg
  - Ajusta a ordem de boot na UEFI (Garuda como primeiro)

--------------------------------------------------------------
ORDEM DO MENU DO GRUB
--------------------------------------------------------------

  1. Garuda Mokka   (padrao)
  2. Garuda Sway
  3. Windows 11
  4. Arch ML4W OS
  5. CachyOS
  6. NixOS 25.11

=== LICOES DO INCIDENTE 13/07/2026 ===
Sintoma: grub-btrfs-snapper.service falhando (exit 126) e
grub-mkconfig com "Operacao nao permitida" ao gravar grub.cfg.

Causas e correcoes:
1. /boot/grub/grub.cfg estava IMUTAVEL (chattr +i)
   -> sudo chattr -i /boot/grub/grub.cfg
   -> NAO reaplicar +i: quebra grub-mkconfig e grub-btrfs silenciosamente
2. /etc/grub.d/41_snapshots-btrfs sem permissao de execucao
   -> sudo chmod +x /etc/grub.d/41_snapshots-btrfs

Verificacao:
   sudo lsattr /boot/grub/grub.cfg   (nao pode ter "i")
   ls -la /etc/grub.d/41_snapshots-btrfs   (precisa do "x")
